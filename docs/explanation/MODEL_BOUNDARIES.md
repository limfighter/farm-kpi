# 왜 전국 소득 통계를 바로 재배 의사결정에 쓰지 않는가

**설명 문서:** 실행 절차는 [빠른 시작](../how-to/GET_STARTED.md), 단위·필드는 [데이터 계약](../reference/DATA_CONTRACTS.md) 참고.

## 1. 선택지는 작물이 아니라 ‘작물 × 시설 × 작기 × 면적 × 판로’

2024년 농촌진흥청의 51개 행은 비교 가능한 *조사 단면*이지, 3,000평 현장에 즉시 복제할 수 있는 재배 계획이 아닙니다. 같은 오이라도 신축 시설/임대/기존 시설 여부, 난방 설비, 노동 공급, 매출 수령 월이 다르면 자금과 위험 프로필이 달라집니다. 또한 3,000평은 **대략적 전체 필지 규모**이지 실제 정식 가능 면적이 아닙니다.

## 2. 서로 다른 네 종류의 ‘이익’

| 지표 | 무엇을 뜻하나 | 곧바로 의미하지 않는 것 |
| --- | --- | --- |
| RDA 소득 | 조사 단위 10a·해당 작기에서 총수입−경영비 | 시설 신설 자금 회수, 실제 수령 현금 |
| 사업 NPV | 모델 할인율·현금 흐름 가정의 결과 | 대출 가능액, 실측 매출 |
| 경제적 NPV | 자기 노동의 경제적 기회비용 등을 고려한 모형치 | 실제 임금지출 |
| 월별 필요자금 | **가정된 판매·대출·투자 시점**의 현금 부족액 | 은행 확정 대출한도, 확정 손실확률 |

RDA 경영비에는 고용노동·시설 감가상각 등 조사 회계 항목이 포함될 수 있습니다. 이를 그대로 모형 운영비에 넣고 고용노동/신축 CAPEX를 다시 반영하면 **이중 계산**됩니다.

## 3. 작기와 시설의 시간 차이

- 인삼(4년근): 원본 수치는 **4년 1기작**으로 표시됩니다. 단순히 4로 나눠 가상의 연간 현금흐름을 만들지 않습니다.
- 과수: 기존 수확 중인 성목 평균과 **신규 식재의 비생산 기간**은 다릅니다.
- 시설 작물: 기존 생산자의 시설 감가상각은 **새 하우스 총 건설비**가 아닙니다. 계약금·잔금·수리비·전기 인입·난방·보증금 회수 시점이 별도입니다.

## 4. 관측, 보고, 가정의 섞임 금지

기상청 ASOS 관측은 실제 기상 특성이지만, 해당 기온에서 특정 작물이 몇 % 손실됐는지까지 입증하지 않습니다. 2024 전국 평균 소득이나 도매가격이 현장 실수취가 되는 것도 아닙니다. 증거가 없는 빈칸은 **미확인**으로 표시하고, 필요하면 *명시적 가정 기반 시나리오*로만 따로 계산해야 합니다.

그래서 지금은 51개 작목 모두 비교 대상으로 열어두고 **토양·수자원·인허가·노동·자금·판로** 자료를 확보한 뒤 다목적 비교를 설계합니다. 하나의 소득순위만으로 투자하지 않습니다.

**기록된 설계 결정:** [작물 선선택 금지 ADR](../decisions/0001-evidence-first-open-crop-choice.md), [비공개 자료 격리 ADR](../decisions/0002-private-data-boundary.md).
