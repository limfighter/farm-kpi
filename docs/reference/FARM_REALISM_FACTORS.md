# 현실 농사 변수와 조건부 경쟁우위 — 모델 누락 감사

**대상:** Farm KPI 모델 담당자·실제 운영자. **기준:** 2026-10-15 현재 기능. 농지 실측/계약/시설 견적 및 투자 승인에 관한 검증은 아니다. 현재 결론은 [상태 문서](../STATUS.md)에서만 관리한다.

- [다년 모델](../../src/farm_strategy/lifecycle.py): 상위 필드 **14개**, 작업 사건 필드 **10개**, 판매 사건 필드 **13개**, 시설 사건 필드 **7개**.
- [현장 조사 모듈](../../src/farm_strategy/site_intake.py): 공통 현장 게이트 **12개**, 단일 수치 항목 **4개**, 운영자 월별 가용시간 **12개 슬롯**.

- 위 필드 수는 **스키마 키**이다. 이름·월·출처ID도 포함하며 독립 경제변수의 수나 실제 실측·검증 완료율이 아니다. 계산할 수 있다는 뜻은 시설 난방비를 현금원장에 입력할 수 있다는 정도이며 난방 부하와 전력 용량을 물리적으로 검증한 것은 아니다.

## 2. 수익률보다 먼저 확인할 실무 조건

| 질문 | 현재 취약점 | 확인해야 할 근거 |
| --- | --- | --- |
| 실제 경작 가능 면적과 시설·재배의 법적 허용범위는? | 3,000평은 총면적이며 작부 가능 면적 아님 | 현장/지형/지목·권리·허가 |
| 토양 배수·pH/EC·관수량·수질이 작형에 맞는가? | 준비도 조사만 있고 작형별 수질/토양 반응 미계산 | 실물 시료 검사, 관정 용량, 배수 이력 |
| 노지/시설의 서리·폭우·정전 위험을 감당할 수 있는가? | 관측소 기상자료는 개별 필지 피해율 아님 | 필지 미기상과 재해·장애·대응 로그 |
| **수확 성수기 주/일 피크**의 고용·선별 작업이 가능한가? | 현 모델은 월별 노동 합계 중심 | 수확일별 작업기록/인력 예약 |
| 구매처가 실제 수량·등급을 정산해 주는가? | 도매가격은 농가 실수취가 아님 | 정산서, 계약, 수수료·반품·입금 조건 |
| 첫 매출까지 건설비·월 지출·위험 충격을 버틸 수 있는가? | 세금, 대출 상환, 현금 완충 미구현 | 비공개 자금 한도·견적·금융 상환 일정 |

**UNKNOWN은 0도, 부적합도, 가능 승인도 아니다.** 미확인 작물은 비교 대상에서 삭제하지 말고 검증 보류로 남긴다. 서면·현장 확인 후 특정 시설/작형이 불가능하다고 판단되면 해당 대안만 보류/배제하며 전체 작물 자체를 배제하지 않는다.

## 3. 다중 변수 상호작용이 가장 중요하다

출하량, 수취가격, 상품화율, 노동, 난방비는 서로 독립이 아니다. 다른 계절에 출하하는 시설작형은 가격 상승과 동시에 연료비·재배기간·병해·피크 노동이 달라진다. 같은 면적에 두 작물을 설정하면 정식/수확 **월뿐 아니라 주별 피크 작업과 토지 점유기간**을 함께 검사해야 한다. 단일 전국 평균 소득을 면적에 곱하거나 작물별 가상 이익을 단순 합산하면 안 된다.

실수취 매출은 상품 수량×등급별 거래단가에서 수수료·공제·반품을 차감한다. 운영 기여액은 여기에 자재·외주·고용·시설 에너지·보관·포장·수송·수리를 차감해 계산해야 한다. 자기노동 기회비용·감가상각·세금·대출은 별개이며 **운영 기여액은 세후 순이익이 아니다**. 시설 CAPEX·임대 보증금은 별도 현금 흐름이다.

### 전략적 이점은 증거가 있는 순증분만

| 선택 | 가능 이점 | 반드시 같이 고려할 불리함 |
| --- | --- | --- |
| 시설 신축·임대·기존 시설 | 출하시기 연장, 품질·상품률 관리 | 투자비·임대료·난방·정전·수리·계약 위험 |
| 관수 정비·토양 처방 | 품질 안정, 과잉 투입 감소 | 수질·물량·초기 공사·유지비 |
| 농기계 임대·작업 위탁 | 구매 자본 절약, 인력 부족 완화 | 예약 실패·운반비·연료·적기 미준수 손실 |
| 복수 품목·윤작·작형 분산 | 가격 위험 분산과 유휴 면적 활용 | 토지/피크 노동 겹침, 장비 재설정 비용 |
| 구매처 계약·직거래 | 안정적 판로와 실수취 개선 가능 | 등급·수량 계약, 포장·CS·반품·미수 위험 |
| 선별·냉장·저장 | 상품화율과 판매 시점 개선 | 에너지·감모·품질저하·추가 노동 |
| 설비 공유·재사용 | 중복 투자 축소 가능 | 적법 사용권, 공동 비용, 다른 사업 운영 충돌 |

어느 선택도 일률적으로 +5% 이득처럼 가정하지 않는다. **증분 영업기여, 초기 투자·피크 부족자금, 현금 회복기간, 주간 노동, 불리한 기상/가격 시 손실**을 같은 조건으로 비교한다.

## 4. 다음 구현 우선순위

**P0:** 면적·허가·배수·용수/수질·전력·필지 재해·실구매처·피크 주간 노동·현실 견적·자본 한도. 특히 등록부의 P0 미구현: 수질, 침수, 수확기 주간 노동, 피해량, 금융 원장 등. 필드가 있다는 것만으로 실증에 성공하지 않는다.

**P1:** 등급별 거래·상품화율, 포장·냉장비, 노동자 확보 가능성, 시설 열량·관수량, 기계화 자가/임대/외주 비교, 대출 상환·세금·보험, 품종별 손실. 실제 농가 영농기록과 지급/정산 증빙 우선.

**P2:** 공동 시설, 연속 작부, 분산판매·계약재배, 저장·가공 등 선택권의 가치. 실증 없이 ROI·손실확률·작물 종합 순위를 만들어 내지 않는다.

## 6. 동일 농장 조건의 대안 간 차액을 실제로 계산

시설 신축/임대·기계화 방식·판매채널 등 **같은 작물, 같은 필지 지역, 경작 면적, 시작연도, 투자기간, 할인율, 자가노동 가치 및 월별 가용 노동 한도**인 두 운영 시나리오만 [증분 비교 함수](../../src/farm_strategy/option_tradeoffs.py)로 비교할 수 있다. 대안−기준의 예상 순정산액, 운영현금비, 영업 기여액, CAPEX, 기말 현금, 최대 월말 자금 부족, 사업/경제적 NPV, 자가·고용 노동 및 피크 과부하를 따로 보고한다.

**경고:** 비교사례가 둘 다 가상이면 결과도 가상차이다. 시설 임대가 CAPEX를 줄이면 운영비는 늘 수 있으며, 생산량을 임의로 증가시키지 않는다. 같은 작물 비교라도 물 공급/실제 구매처/토양 적합성·시세/재해확률·주간 인력·진짜 공사비가 확인되지 않으면 유리한 사업이라는 결론을 내리지 않는다. 면적이나 시간 가정이 다르면 비교 자체를 거절한다.

실행: python scripts/compare_options.py --input data/templates/multiyear_scenarios_SYNTHETIC.json --output output/paired-option-deltas.json --html output/paired-option-deltas.html

## 7. 수확기 주간 노동과 등급별 실수취

[추가 계산 모듈](../../src/farm_strategy/execution_detail.py)은 수확·관리 작업의 실제 날짜별 자가/고용 노동을 월 원장과 대조하고, 주별 실제 가용시간이 확인된 때만 초과분을 계산합니다. 미기재 주간 공급은 UNKNOWN입니다. 등급별 상품 판매수량 합계는 원래 출하 수량×상품화율과 정확히 같아야 하며 기존 판매를 교체합니다. 출하 시 포장비와 수수료·공제를 나누어 입금 월에 반영합니다. 냉장·저장·반품은 아직 별도 모델 미구현입니다.

방법 참고: [농사로 2026 농산물소득조사표](https://www.nongsaro.go.kr/portal/ps/pst/pstb/pstbc/mngmtDtaDtl.ps?menuId=PS03213&nttSn=845&pageIndex=1), [농촌진흥청 적기 수확·선별 안내](https://www.rda.go.kr/board/board.do?dataNo=100000811620&mode=view&prgId=day_farmlcltinfoEntry). 원문 조사표/안내가 이 모델의 합성 노동·가격을 검증했다는 뜻이 아닙니다.

실행: `python scripts/assess_execution.py --input data/templates/execution_detail_SYNTHETIC.json --output output/execution-detail-example.json --html output/execution-detail-example.html`.
