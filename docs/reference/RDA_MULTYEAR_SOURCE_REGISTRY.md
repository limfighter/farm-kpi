# 농촌진흥청 다년도·지역 소득자료 출처 등록부 (P1-01)

**목적:** 2022~2024년 공식 자료의 존재와 **검증된 수치 행**을 분리합니다. **대상:** 자료 조사·모형·대시보드 구현자. **현재 상태:** 공표 출처는 확인, 정밀 수치 전사는 **2024 전국 51개만** 완료했습니다. 작물·재배방식·시설·대출은 미결정입니다.

## 확인된 공식 발행 자료

| 조사연도 | 전국 자료집 | 지역별 자료집 | 현재 데이터 행 |
| --- | --- | --- | --- |
| 2022 | [농사로 공식 첨부 확인](https://www.nongsaro.go.kr/portal/ps/pst/pstb/pstbc/mngmtDtaDtl.ps?menuId=PS03213&nttSn=819) | 동일 게시물 지역 자료집 존재 | **0**: 정밀 숫자 미전사 |
| 2023 | [농사로 공식 첨부 확인](https://www.nongsaro.go.kr/portal/ps/pst/pstb/pstbc/mngmtDtaDtl.ps?menuId=PS03213&nttSn=833) | 동일 게시물 지역 자료집 존재 | **0**: 정밀 숫자 미전사 |
| 2024 | [농사로 공식 첨부 확인](https://www.nongsaro.go.kr/portal/ps/pst/pstb/pstbc/mngmtDtaDtl.ps?menuId=PS03213&nttSn=842) | 동일 게시물 지역 자료집 존재 | **전국 51개만**, 지역별 **0** |

게시물에 첨부된 자료집이 존재한다는 사실은 **각 작목의 전북 표본·숫자가 존재한다거나 전주 필지에 적용 가능하다는 증거가 아닙니다**. 2025년 소득 *실적* 자료집은 이번 확인 범위에서 검증하지 못했습니다. 2025년 조사방법·조사표와 2025년 실적 공표는 다릅니다.

추가 공식 탐색 경로: [농산물소득정보 시각화](https://www.nongsaro.go.kr/portal/ps/psb/psbf/agricultIncomeInfoLst.ps?menuId=PS65441), [2014년 이후 소득정보](https://www.nongsaro.go.kr/portal/ps/psb/psbf/frmprdIncomeInfoNew.ps?menuId=PS03617). 웹 화면의 연도별 차트는 천원 단위로 반올림될 수 있고, 국가·지역 표시가 섞일 수 있으므로 **그래프에 보이는 수치를 1원 단위 원본으로 복제하지 않습니다**. API 코드북은 실데이터로 간주하지 않습니다.

농사로는 공개 데이터 화면에 **공공누리 제2유형(출처표시·상업적 이용금지)**을 표시합니다. 새 데이터 수집·재배포 시 원저작물별 조건을 재확인하세요.

## 등록 파일과 행 계약

- [자료집 출처 메타데이터](../../data/metadata/rda_income_source_registry.json): 출처 ID·조사연도·범위(NATIONAL/REGIONAL_PUBLICATION)·공표 확인 상태·수치 전사 상태·실제 행 수.
- [검토된 long-format 관측 행](../../data/reported/rda_income_long.csv): **2024 전국 51행**만. 연도·지역·작목ID/재배방식 이름·작기 연수·2024 명목 원/10a/작기·자가/고용 노동 시간·페이지·출처 R·비교 경고를 명시합니다.
- [기준 2024 원문 대조](../../data/reported/rda_2024_all_51_crop_candidates.csv): 2024년 51개 수치 전사의 기준. 기준 원자료 해시·페이지는 기존 감사 파일에 유지합니다.
- [검증 명령](../../scripts/check_crop_income_history.py): 중복 작물-연도-지역, 무근거 지역/연도 행, 원본 51행 드리프트, 4년근 인삼의 1년 변경, 총수입·경영비·소득 오차, 자가/고용 노동 합계 등을 차단합니다.

`rda_income_long.csv`에서 **행이 없다는 것은 숫자 0이나 재배 부적합이 아닙니다.** `region=NATIONAL`과 `JEONBUK`은 서로 대체 가능하지 않습니다. 장기 표에 있는 2024 소득은 신규 시설 신축 현금수익·실제 3,000평 부지 실적·연 단위 작물 소득으로 자동 환산되지 않습니다. 인삼(4년근)의 `cycle_years=4`를 반드시 유지합니다.

## 실행 방법과 다음 검증 문턱

```bash
python scripts/check_crop_income_history.py --check
python -m pytest -q tests/test_crop_income_history.py
# 2024 기준 CSV만 변경되고 새 정밀 관측 행이 없는 경우에 한해:
python scripts/check_crop_income_history.py --refresh-baseline
```

1. 2022·2023 자료집 PDF의 해당 **작목/조사연도/지역/작기/표 쪽수**와 전국·전북 수치가 실제 제공되는지 확인합니다. 자료에 없는 항목은 숫자 대신 **미확인/미공표 사유**로 남깁니다.
2. 전국·지역 표본 대상과 작목명이 달라질 수 있으므로, 이름 문자열만으로 매핑하지 않습니다. 지역자료의 개별 전북 행은 표본·정의 확인 후 별도 원문 대조를 거칩니다.
3. 검증된 수치가 확보되면 출처 메타데이터의 전사 상태와 행 수를 수정하고 long-format CSV에 **해당 원문 PDF 페이지**를 기록합니다. 새 지역/연도·특별 작기의 스키마 수용은 별도 테스트와 PR 리뷰가 필요합니다.
4. **가격·소득 비교 시 2024 명목값을 다른 해의 실질값처럼 결합하지 말고**, 설비 감가상각/고용비 포함 여부와 4년 작기를 확인합니다.
5. 수치와 함께 CI·[현재 상태](../STATUS.md)·[수치 업데이트 절차](../how-to/UPDATE_REPORTED_DATA.md)·탐색 화면을 같은 PR에서 조정합니다. 숫자 증빙이 확보되기 전 기존 51개 탐색 화면의 수익 추천·순위는 확장하지 않습니다.

**미해결:** 실제 2022/2023 정확한 작목별 수치, 2024 지역별 전북 수치, 지역과 전국의 비교가능성 심사, 시계열 UI, 현장 12개 게이트, 지역 구매처·견적, 범용 현금흐름. P1-01은 **출처 탐색/데이터 계약 준비 단계**이며 수치 수집까지 완료됐다는 뜻이 아닙니다.
