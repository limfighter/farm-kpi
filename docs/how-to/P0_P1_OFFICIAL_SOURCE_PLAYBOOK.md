# 전주 인근 독립 농지 — 실제 해결 경로와 공식 정보처 (P0/P1)

**목적:** `docs/STATUS.md`의 미완료 과제 [#5](https://github.com/limfighter/farm-kpi/issues/5), [#6](https://github.com/limfighter/farm-kpi/issues/6), [#7](https://github.com/limfighter/farm-kpi/issues/7), [#8](https://github.com/limfighter/farm-kpi/issues/8)를 해결하기 위해 **직접 조회 가능한 공식 사이트, 문의 기관, 준비자료, 증거 통과 기준**을 연결한다.  
**대상:** 농지 운영자·데이터 검증 담당·개발자.  
**조사일:** 2026-10-15. **상태:** 출처·절차 확인 완료, 실제 필지·현장·거래 검증 **미완료**. 이 문서는 **지원금 자격 확인서, 허가 또는 대출 승인, 특정 작물 추천**이 아니다.

## 먼저 지켜야 할 데이터 경계

- 필지는 “전주 인근 약 3,000평”만 확인됐다. **주소·지번·좌표·임대차·계약서·자금·개인 연락처를 Issue나 Git에 올리지 않는다**. 해당 정보는 관할 행정기관/공급업체에만 전달하거나 `data/private/`에 보관한다.
- 일반 공표값은 **R**, 현장 측정값은 **O**, 실제 정산은 **T**, 서면 견적은 **Q**, 시뮬레이션 가정은 **A**. `UNKNOWN`과 0을 구별한다.
- 정책사업의 **모집 기간, 예산, 자격, 금융 금리·보증**, 구체적 건축/농지 사용허가는 접수 당시의 공식 공고와 관할기관 판단이 필요하다.
- 농사로 조사실적의 원/10a/작기는 해당 필지 연간 이익이나 신규 시설투자의 NPV가 아니다.

**완료 조건:** 실제 경작 가능 면적, 토양·배수, 수원·용수, 이용 제한, 전력·차량 접근성, 시설 인허가에 대한 **날짜와 근거**가 있는 승인/불가/미결 항목이 구분될 것. 지도 조회 자체는 승인이나 현장 실측이 아니다.
