# 세션 02 — 독립 필지의 물리·법적 조건

**목적/대상:** 운영자와 현장 검토 담당자가 재배·시설 검토의 실제 필지 제약을 수집할 작업 지시서다.  
**연결:** 로드맵 P0-03 · [Issue #5](https://github.com/limfighter/farm-kpi/issues/5). **문서 성격:** 실행 계획이며 실제 현황은 [STATUS](../STATUS.md)만 따른다.  
**책임:** 운영자가 비공개 자료를 제공하고 토양·용수·허가 담당기관이 해당 범위를 확인한다. 개발자는 기록/형식 검증을 지원한다.

## 입력과 경계

- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md), [현장 입력 절차](../RDA_AUDIT_AND_SITE_INTAKE.md), [입력 계약](../reference/DATA_CONTRACTS.md)을 읽는다.
- 약 3,000평은 총면적 설명이다. 실제 경작가능 면적·소재 관할은 미확인부터 시작하며 가족 배 과수원·별도 버섯사업은 제외한다.
- 01·03~06 완료 없이 수집할 수 있다. 정확한 주소·좌표·지번·계약·검정 원본은 ignored `data/private/`에만 둔다.

## 실행 순서

1. 운영자가 비공개로 소재 관할과 사용권·현황을 확인한다. 토지이음·농지대장 조회는 규제 검토의 시작이며 허가가 아니다.
2. 경작가능/도로/배수로/기존 구조물 면적을 구분하고 측정일·방법·오차 범위를 남긴다. 전체 면적을 자동 정식 면적으로 쓰지 않는다.
3. 흙토람 지도와 현장 토양검정을 구분한다. pH·EC·배수·침수 이력은 시료 위치/시기·검토 범위와 함께 비공개 기록한다.
4. 수원·수량·수질·계절 공급·사용권 및 관정 허가/신고를 확인한다. 지도상의 관정 존재를 사용 가능 판정으로 바꾸지 않는다.
5. 전력 용량·인입, 차량 접근·저장/물류, 기존 시설 상태를 확인한다. 시설 가정별 법적 요건은 관할 농지/개발행위/건축 부서의 회신과 구분한다.
6. 운영자가 별도 승인한 현장조사·문의만 수행하고 에이전트는 미승인 연락의 초안을 준비한다. 상담과 실제 허가를 분리한다.
7. 기존 양식에는 허용 상태와 비식별 참조만 기록한다. 독립 검토의 물리/법적 통과·불가·미결 판단은 별도 근거표에 두며 양식 상태를 VERIFIED로 올리지 않는다.

## 예상 산출물

- 기존 빈 양식의 로컬 사본 `data/private/site-facts.json` 및 비공개 `data/private/site-review.md`에 항목별 날짜·출처 O/R/Q/T·검토자·판단 범위를 남긴다.
- `output/site-status-redacted.json`은 상태 개수·누락항목 확인용이다. 문서 확보·형식 통과를 현장 적합성 승인으로 설명하지 않는다.
- [현장 입력 절차](../RDA_AUDIT_AND_SITE_INTAKE.md)에는 비식별 절차 개선만 반영하고, STATUS/#5에는 실제 충족도와 다음 확인 항목만 요약한다.

## 검증 명령과 통과 기준

개인 입력 사본이 준비된 뒤 저장소 루트에서 실행한다. 출력과 원본 모두 커밋하지 않는다.

```bash
farm-strategy site-check --file data/private/site-facts.json --output output/site-status-redacted.json
python -m pytest -q tests/test_site_intake.py tests/test_site_intake_ui.py
python scripts/build_feasibility.py --check
python scripts/check_docs.py --check
```

**통과:** 면적·토양/배수·용수·사용/허가·전력·접근성 각각에 근거/날짜 또는 명시적 미확인 사유가 있고, 물리 조건과 법적 판단이 구별된다.  
**차단/인계:** 미제공/미회신은 UNKNOWN 또는 FOLLOWUP_NEEDED다. 증빙 없는 후보의 재무 진입·시설 발주는 보류하되 다른 수집은 계속한다. 실제 불가도 해당 작물/방식/규모 범위에 한정한다.
