# 목표 달성을 위한 세션별 실행 계획

**목적:** 전주 인근 독립 농지의 작물·재배방식·면적·판로를 근거에 따라 비교하고, 시험재배·추가 조사·보류·투자 검토 중 다음 행동을 결정할 수 있도록 작업을 나눕니다. **대상:** 운영자·조사 담당·개발자. **작성일:** 2026-10-15.

이 문서와 개별 파일은 **실행 계획**입니다. 현재 완료 여부·자료 충족도·다음 착수 대상은 [STATUS](../STATUS.md)만 갱신합니다. 계획 작성이나 코드 병합으로 근거가 확보되었다고 판정하지 않습니다. 우선순위와 전체 목표는 [실행 로드맵](../FARM_DECISION_EXECUTION_PLAN.md), 필드·단위는 [데이터 계약](../reference/DATA_CONTRACTS.md)을 따릅니다.

## 모든 세션의 시작과 종료

1. [AGENTS](../../AGENTS.md)와 필수 문서, 최신 STATUS, 해당 세션 문서를 읽습니다. GitHub에서 최신 `main`, 열린 PR, 정확한 HEAD의 CI를 확인해 기존 작업과 겹치지 않게 합니다.
2. 입력 자료의 존재·검증 범위와 이번에 끝낼 산출물 한 가지를 정합니다. 외부 자료가 없으면 누락 사유·확인 경로·다음 책임자를 기록합니다. 대기 때문에 독립적인 검증/설계 작업까지 멈추지 않습니다.
3. 원본·개인정보는 ignored `data/private/`, `data/raw/`, `output/`에 둡니다. Git에는 허용된 비식별 메타데이터/해시와 이용조건을 검토한 자료만 저장합니다. 문의 문안 작성과 실제 발송은 구별하며, 이 계획은 외부 연락의 자동 발송 지시가 아닙니다.
4. 변경 범위의 회귀 검사, 문서 카탈로그·링크 검사와 전체 테스트를 실행합니다. 코드/데이터 변경은 [CI](../../.github/workflows/ci.yml)의 관련 생성·출처 검사를 모두 통과해야 합니다. 원본 없이 실행할 수 없는 검사는 생략 이유를 명시합니다.
5. 같은 PR에서 STATUS의 다음 행동·남은 근거와 관련 문서를 갱신합니다. PR에 세션 ID, 실제 산출물, 입력/출처/단위, 검증 명령·결과, HEAD SHA, push/PR CI URL과 차단사항을 남깁니다. 새 문서는 [카탈로그](../catalog.json)에 등록합니다.
6. 미래 PR의 병합에는 해당 작업의 사용자/유지관리자 승인과 정확한 HEAD의 통과 CI가 필요합니다. 이 실행 계획이 향후 모든 PR·구매·대출·시설 투자를 승인하지는 않습니다.

**두 종료 기준:** 재현 가능한 문서·도구가 만들어지면 해당 개발 산출물은 완료할 수 있습니다. 필요한 실측/서면 근거가 없으면 해당 의사결정 게이트는 계속 UNKNOWN/대기로 남깁니다. 검토하지 않은 사실을 VERIFIED로 승격하지 않습니다.
