# 세션 05 — 노지·신축·임대·계절시설 대안

**목적/대상:** 운영자와 시설/회계 검토 담당자가 같은 범위의 시설 대안과 현금지급 조건을 비교할 작업 지시서다.  
**연결:** 로드맵 P1-03 · [Issue #8](https://github.com/limfighter/farm-kpi/issues/8)의 시설 부분. **문서 성격:** 실행 계획이며 실제 현황은 [STATUS](../STATUS.md)만 따른다.  
**책임:** 운영자가 검토 범위를 정하고 업체/임대인은 서면 조건 Q, 검토자는 포함/제외와 인허가 선행조건을 확인한다.

## 입력과 경계

- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md), [모델 경계](../explanation/MODEL_BOUNDARIES.md), [비공개 검토 절차](../PRIVATE_CALIBRATION_PREVIEW.md)를 읽는다.
- 01~04·06 완료 없이 대안·견적 범위를 수집할 수 있다. 02의 면적/용수/법적 조건이 미확인이면 조건부 견적이며 실행 가능 판정은 보류한다.
- 주소·원본 견적·계약·금융 조건은 ignored `data/private/`에 보관한다. 문의/현장방문은 운영자가 별도 승인한 범위에서만 수행하며 발주·서명·차입은 별도 결정이다.

## 실행 순서

1. 노지 유지, 계절 피복, 임대, 신축, 외주작업 조합을 열어둔다. 비교 단위는 작물×시설×작기×실사용 면적이며 3,000평 전부를 시설 면적으로 가정하지 않는다.
2. 동일 면적·높이·동수·피복·골조·내재해/설비 성능·작기 조건의 요청서를 만든다. 서로 다른 사양은 차이를 명시한다.
3. 실행 가능성 검토 대상 시스템마다 2~3개 비교 가능한 서면 패키지를 목표로 한다. 견적 수/대안 부족은 결측으로 남기며 임의 단가를 만들지 않는다.
4. 부지정리·배수·기초·관수·전력인입·난방·환기·저장·운반·노무·세금/보험·허가·해체비의 포함/제외·수량·유효기간을 대조한다.
5. 계약금·중도금·잔금·공기·검수·수리·교체·철거·잔존가치, 임대료·보증금 지급/반환·원상복구·중도해지 조건을 분리한다.
6. Q는 서면 견적, T는 실제 지급으로 유지한다. RDA 감가상각과 새 CAPEX·리스 현금·수리비를 구별하고 경영비/고용비 중복을 표시한다.
7. 02의 인허가/용수/전력, 03의 자금 제약과 대조할 목록을 인계한다. 보조금·대출은 승인 전 가용자금에 포함하지 않는다.

## 예상 산출물

- 비공개 `data/private/facility-options-review.md`에 대안별 사양·비용구성·지급월/조건·제외항목·Q/T·날짜·검토자와 미확인 이유를 기록한다.
- 개인 현장 입력의 `startup_capex_quotes`는 허용된 수집 상태만 표시한다. 검토된 환산 후보가 필요하면 기존 비공개 증빙/검토 양식으로 별도 작성한다.
- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md)에는 재사용 가능한 비교 절차만, STATUS/#8에는 확보 범위만 반영한다. 기존 `configs/base.json`은 자동 변경하지 않는다.

## 검증 명령과 통과 기준

견적 범위·지급조건은 원문 대사가 필요하다. 아래 검사는 도구·회계 회귀이며 시설 적합성/가격 진위를 승인하지 않는다.

```bash
farm-strategy evidence-check --file data/templates/private_evidence_TEMPLATE.csv
python -m pytest -q tests/test_evidence.py tests/test_calibration.py tests/test_finance_regressions.py
farm-strategy validate
python scripts/check_docs.py --check
```

**통과:** 대안마다 동일 사양 비교 여부와 비용·지급/반환·유효기간·제외범위가 보이고, 2~3개 패키지 확보 또는 정확한 부족 사유가 있다. 현금 CAPEX와 감가상각을 혼합하지 않는다.  
**차단/인계:** 견적·허가·자금이 미확인이면 그 대안의 투자평가는 보류한다. 노지/임대 등 다른 대안 수집은 계속하며 문서·코드 PR 병합을 농업 투자 승인으로 해석하지 않는다.
