# 세션 09 — 불확실성과 다목적 비교

**목표:** 비교 가능한 후보의 하방 결과·자금 부족·노동 피크·첫 수입 시점을 나란히 보여주고 운영자의 제약을 적용합니다. **책임:** 모델·개발 담당, 제약 선택은 운영자. **로드맵:** P2-02. 현재 상태는 [STATUS](../STATUS.md)에만 기록합니다.

## 입력·선행조건

- [08 후보 모형](08-evidence-gated-model.md)의 입력/출력 계약, 검토된 제약과 근거, 후보별 비교가능성 표.
- [03 노동·자금](03-labor-and-capital.md)의 실제 제약이 없으면 통과 여부를 UNKNOWN으로 표시합니다. 임의 자금/시간 상한을 만들지 않습니다.
- [06 위험 자료](06-weather-and-agronomy.md)가 분포를 검증하지 못하면 분석을 명시적인 가정 민감도로 제한합니다.

## 실행 순서

1. 필수 근거를 통과한 후보, 문서상 막힌 후보, 미확인 후보를 별도로 표시합니다. pending을 0수익/부적합으로 변환하지 않습니다.
2. 같은 단위·가격 기준연도·기간·작기·면적 처리로 비교 가능한지 확인하고 불가능한 쌍과 이유를 표시합니다.
3. 가격·생산·임금·수리·정산 지연·시설비·차입 불가/축소의 불리한 가정별 민감도를 정의합니다. 분포 선택과 상관관계의 근거/가정 상태를 출력합니다.
4. 금융 NPV, 자기노동 고려 결과, 월말 필요자금, 월별 노동과 회수 시점을 분리합니다. 객관식 단일 점수나 무근거 위험확률을 만들지 않습니다.
5. 충분히 비교 가능한 실현 가능 후보만 Pareto/지배관계 검토에 넣고, 운영자의 상한을 적용합니다. 우열 불명·후보 없음·추가 조사·보류도 정상 결과로 반환합니다.

## 산출물·완료/대기 기준

- 비교 계약, 가정과 근거의 연결 표, 비교 모듈·회귀 검사와 시나리오별 결과. 사적 입력 결과는 ignored `output/`에 보관합니다.
- 단위 불일치·동일 후보·전부 pending·전부 제약 초과·분포 근거 없음·Pareto 동률을 검사합니다.
- 공통 난수 비교를 확장하면 경로별 충격 정렬과 차이의 재현성을 유지합니다. 합성 손실 비율을 실제 발생확률로 부르지 않습니다.
- 비교 대상/제약이 부족하면 차단 이유를 제공하며 최적 작물을 자동 선정하지 않습니다.
