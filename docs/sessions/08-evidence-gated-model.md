# 세션 08 — 근거가 연결된 작물×시설×작기 모형

**목표:** 조사된 후보의 면적·작기·시설·노동·판매·금융 시점을 연결하는 월별 현금흐름 모형을 설계하고 작은 후보 범위부터 구현합니다. **책임:** 모델·개발 담당과 운영자 검토. **로드맵:** P2-01. 현재 충족도는 [STATUS](../STATUS.md)를 따릅니다.

## 입력·착수 문턱

- [01~06 근거 수집](README.md)의 후보별 출처·유효 면적·법적/물리적 가능성·월별 노동·자금·판로·시설·위험 자료와 [07 회계 계약](07-accounting-components.md).
- [01](01-public-sources.md)의 조사 밖 후보 등록부도 입력 범위에 포함합니다. `source_available=false` 후보는 탐색 대상/pending으로 보존하고, 숫자를 보간하거나 기존 51행의 수익을 복사해 정량평가에 넣지 않습니다.
- 입력마다 출처 R/O/T/Q/A, 단위, 연도·지역, 작기, 실제 지급/수취 시점, 검토 상태를 연결합니다. Q는 실제 지출 T가 아니고, 가정 A는 검증값이 아닙니다.
- 정보가 부족해도 **작업별 원가·작기/월별 입금과 시설 신축·임대 비교를 실제 실행하는 시뮬레이터 코드와 HTML**을 준비할 수 있습니다. **실제 후보 평가**는 필수 근거가 연결된 후보에 한합니다. 미확인 후보는 pending으로 남깁니다.

## 실행 순서

1. `crop × system × area × cycle × market` 식별자와 입력·출력 계약, 누락 상태, 비교 가능 조건을 설계합니다. 기존 단위·사생활 계약에 영향을 주면 [ADR](../decisions/README.md)로 대안과 근거를 남깁니다.
2. 10a/실경작 면적, 작기/연간, 명목/실질, 비용/감가상각/현금투자, 소유/고용노동을 분리합니다. 임대 보증금·시설 잔존가·대출 지급/상환·원금 잔액을 명시합니다.
3. 충분한 근거가 있는 작은 후보 집합부터 구현합니다. 인삼의 다년 작기와 신규 과원의 미수확 기간은 지원 설계를 갖춘 뒤 포함하며 성목 연소득을 복사하지 않습니다.
4. 월별 판매·비용·투자·금융 합계와 연간/전체기간 합계를 독립 검증합니다. 수입−경영비 통계를 사업 NPV로 자동 변환하거나 기존 다섯 계획을 51행에 복제하지 않습니다.
5. 실제 근거와 합성 테스트/명시적 가정 시나리오를 구별해 출력합니다. 위험 분포가 검증되지 않았다면 실측 손실확률·예측 ROI로 표시하지 않습니다.

## 산출물·완료/대기 기준

- 범용 입력·출력 계약과 모형 설계, `src/farm_strategy/`의 작은 기능 단위, 대응 회귀 테스트, [데이터 계약](../reference/DATA_CONTRACTS.md) 갱신.
- 검증에는 영면적과 결측 면적의 차이, 작기 중첩, 미수확 기간, 비용 이중 계산, 정산 지연, 명목/실질 변환과 월↔연간 정합성을 포함합니다.
- 후보 근거가 부족하면 설계/합성 검사 산출물과 남은 문턱까지만 기록합니다. 비교 후보 완성이나 실제 수익성 검증으로 표시하지 않습니다.

## 선행 구현: 실제 수치 없는 가정형 워크플로우 모형

`src/farm_strategy/workflow.py` + `scripts/compare_workflows.py`는 **합성 입력 3대안**의 작업·노동·운영비·시설비·출하/정산을 월별로 계산합니다. 추가로 [전체 작물 오프라인 입력 화면](../../dashboard/universe/index.html)에서 51개 조사 작목을 모두 선택하고 작목 밖 후보도 추가하여 사용자 자체 작업 기록으로 여러 시설 대안을 비교할 수 있습니다. 51개 작목에 기존 감자·오이 가정을 복제하지 않습니다. 농사로 공식 농작업일정은 51개 중 **10개 작목에 작형·출처 URL·작업 월 범위를 참조 연결**했으며 41개는 미확인입니다. **원문과 실제 운영 작형 간 세부 매핑·시설 견적·실거래 가격·작업별 노동 및 수확량 검증은 미실시**입니다. 다음 작업은 농사로 공식 농작업일정과 실제 운영 장부/견적 기반으로 단계/단가를 한 개 작목·시설씩 교체해 근거 커버리지와 결과 민감도를 보고하는 것입니다. 투자 승인 결과로 표시하지 않습니다.
