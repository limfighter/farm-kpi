# 세션 03 — 월별 노동·고용·자금 한계

**목적/대상:** 운영자와 재무 검토 담당자가 감당 가능한 월별 작업량과 자금 제약을 기록할 작업 지시서다.  
**연결:** 로드맵 P0-04 · [Issue #6](https://github.com/limfighter/farm-kpi/issues/6). **문서 성격:** 실행 계획이며 실제 현황은 [STATUS](../STATUS.md)만 따른다.  
**책임:** 운영자가 시간·자기자금·허용 위험을 정하고, 고용/금융 담당자는 실제 제시 조건을 확인한다. 개발자가 대신 한도를 정하지 않는다.

## 입력과 경계

- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md), [현장 입력 절차](../RDA_AUDIT_AND_SITE_INTAKE.md), [모델 경계](../explanation/MODEL_BOUNDARIES.md)를 읽는다.
- 01·02·04~06 완료 없이 작성한다. 자료 없는 값은 null/UNKNOWN이며 월 노동과 자금을 0으로 채우지 않는다.
- 기존 `configs/base.json`의 예시 시간을 개인 제약으로 복사하지 않는다. 개인 소득·연락처·금융 원본은 ignored `data/private/`에 둔다.

## 실행 순서

1. 운영자가 1~12월 자가 작업 가능시간을 범위·확인일과 함께 기록한다. 다른 일과의 시간 충돌은 제약만 반영하며 가족 사업 수익을 합산하지 않는다.
2. 작업 숙련·기계화·저장·이동의 한계를 기록한다. 연간 RDA 노동시간을 근거 없이 12등분하거나 특정 달에 배분하지 않는다.
3. 월별 고용 가능 인원/시간·업무·단가·추가비·공급 불확실성을 별도 표로 만든다. 인력중개 사업 안내는 실제 배정 확약이 아니다.
4. 투자 가능한 자기자금, 유지해야 할 최소 보유현금, 감당 가능한 현금 부족 한도, 첫 수취까지 허용 개월을 구분한다. 기존 필드와 의미가 다르면 비공개 보조표에 남긴다.
5. 금융/보조금은 공고 자격·상담·심사·승인·집행을 분리한다. 미승인 대출/보조금을 가용자금에 넣지 않으며 무차입 대안의 미확인도 표시한다.
6. 고용 Q/T와 운영자 제약을 구분하고, 자가노동 기회비용과 실제 임금 현금을 분리한다. 경영비의 고용노동·감가상각과 중복 계산하지 않는다.
7. 범위값·고용/금융 보조항목은 기존 JSON에 임의 키를 추가하지 않고 비공개 표에 둔다. 기관/인력/은행 문의는 운영자가 별도 승인한 범위에서만 수행한다.

## 예상 산출물

- `data/private/site-facts.json`의 기존 `operating_constraints`에 확인된 단일값만 입력하고, 월별 범위/고용/자금 근거는 비공개 `data/private/labor-capital-review.md`에 기록한다.
- 기존 양식의 현금완충 한도와 별도 최소 현금 목표를 혼동하지 않는다. 항목별 출처·기준일·검토자·미확인 사유를 유지한다.
- `output/site-status-redacted.json`과 STATUS/#6에는 입력 월수·제약 확보 여부만 남긴다. 개인 시간/금액·심사정보는 공개하지 않는다.

## 검증 명령과 통과 기준

로컬 사본 준비 후 실행한다. 아래 검사는 개인 한도·고용 공급·대출의 진위를 인증하지 않는다.

```bash
farm-strategy site-check --file data/private/site-facts.json --output output/site-status-redacted.json
python -m pytest -q tests/test_site_intake.py tests/test_monthly_cashflow.py
farm-strategy validate
python scripts/check_docs.py --check
```

**통과:** 12개월 각각 값/범위 또는 UNKNOWN 사유가 있고 자가·고용을 구분한다. 자기자금·최소현금·부족 허용한도·첫 수취 대기기간·금융 승인상태가 별도 기록된다.  
**차단/인계:** 운영자가 정하지 않은 한도와 미확약 인력은 후속 후보 재무평가의 미결 조건이다. 양식 작성만으로 #6을 종료하거나 투자·차입을 승인하지 않는다.
