# 세션 04 — 판로와 실제 순정산 조건

**목적/대상:** 운영자와 시장 근거 담당자가 판매 가능 조건·실수취액·입금시점을 비교할 작업 지시서다.  
**연결:** 로드맵 P1-02 · [Issue #8](https://github.com/limfighter/farm-kpi/issues/8)의 판로 부분. **문서 성격:** 실행 계획이며 실제 현황은 [STATUS](../STATUS.md)만 따른다.  
**책임:** 운영자가 접근 가능한 채널과 공개 범위를 확인하고, 검토자는 서면 조건·실제 정산의 차이를 대조한다.

## 입력과 경계

- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md), [출처·단위 계약](../reference/DATA_CONTRACTS.md), [비공개 검토 절차](../PRIVATE_CALIBRATION_PREVIEW.md)를 읽는다.
- 01~03·05~06 완료 없이 판로 근거를 수집한다. 미정 작목은 후보별 문의 조건을 분리하며 특정 작목 선정으로 간주하지 않는다.
- 거래처 연락처·원본 정산서·계약은 ignored `data/private/`에 둔다. 에이전트의 외부 연락은 별도 승인 범위에 한정하며 이 계획 자체로 발송하지 않는다.

## 실행 순서

1. 농넷·농협 공판장 등에서 채널과 품목/등급/지역/단위를 탐색한다. [프로젝트 소개](../../README.md)의 KAMIS 제외 방침을 유지한다. 도매·중도매·소매 공개가격 R은 농가 순수취가 T가 아니다.
2. 실제 접근 가능한 출하/계통/직거래 등 2개 이상 채널의 문의 초안을 만든다. 미확보 채널은 접근 가능하다고 쓰지 않는다.
3. 운영자가 승인해 확보한 서면 조건에 품종·등급·규격·물량 kg·인수 기간·최소물량·거절/반품·수수료·운송·선별·포장·냉장비를 기록한다.
4. 계약상 지급기한과 실제 입금일을 분리하고 인수/경매 후 지연일·미수·공제·세금 처리의 범위를 확인한다. 구두 설명은 서면 Q나 정산 T로 올리지 않는다.
5. 실제 판매 kg을 분모로 `(총정산액−미공제 수수료·선별포장·운송하역·반품감액·기타 직접비)/kg`를 계산한다. 이미 차감된 항목의 중복 차감을 막는다.
6. 같은 품종·등급·기간·인도조건끼리 비교하고 총액/단가/현금입금의 차이를 대사한다. 누락 공제비용을 0으로 두지 않는다.
7. 수취 지연·물량 상한·불합격 조건을 후속 월별 현금흐름 입력으로 인계한다. 공개가격·견적만으로 계약된 구매처나 확정 매출을 선언하지 않는다.

## 예상 산출물

- 비공개 `data/private/buyer-settlement-review.md`에 채널별 조건표·실수취 계산·증빙 참조·확인일·검토자·결측을 남긴다.
- 필요 시 기존 `data/templates/private_evidence_TEMPLATE.csv`를 비공개 사본으로 사용한다. 모델 환산 후보는 별도 검토 전까지 기존 재무설정에 반영하지 않는다.
- [공식 정보처](../how-to/P0_P1_OFFICIAL_SOURCE_PLAYBOOK.md)에는 공개 절차만, STATUS/#8에는 판로 증빙 확보 여부만 요약한다. 시설 부분의 완료 여부와 분리한다.

## 검증 명령과 통과 기준

원본·총액 대사는 사람이 수행한다. 아래 기존 검사는 출처 분류/입력 도구 회귀를 확인하며 실제 거래를 인증하지 않는다.

```bash
farm-strategy evidence-check --file data/templates/private_evidence_TEMPLATE.csv
python -m pytest -q tests/test_evidence.py tests/test_calibration.py
python scripts/check_docs.py --check
```

**통과:** 2개 이상 접근 가능한 채널에 비교 가능한 서면 조건이 있고, 확보한 실제 정산은 kg·공제·입금일을 재계산할 수 있다. Q/T/R과 미확보 거래를 구별한다.  
**차단/인계:** 조건/정산이 없으면 해당 채널의 순수취·물량·입금은 UNKNOWN이다. 근거 부족은 후속 재무평가를 막으며, 시설 수집은 계속한다. 판로 수집만으로 #8 전체를 닫지 않는다.
