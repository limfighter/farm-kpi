## 다음 단계(우선순위)

**2026-10-16 선행 점검:** 새 작물 예측 기능을 늘리기 전에 [코드 결함과 농사 현장 근거 부족](reference/FARM_READINESS_GAP_AUDIT.md)을 분리했습니다. 코드 중복·결측·날짜/자원경고는 보완하였지만 **현장 경작 적합성·정산·견적·금융승인 검증은 0건**으로 여전히 UNKNOWN입니다.


**우선 제품 목표는 실제 농장 농작업→생산·출하→월별 비용·정산→작물×시설 대안 수익 비교입니다.** 출처 검증은 그 입력의 신뢰도를 확보하는 병렬 연구입니다. **모형 개발은 외부 현장 근거가 모두 모일 때까지 기다리지 않고, 가정 표시가 분명한 시뮬레이터부터 진행합니다.** 이 시험 모형의 출력은 검증된 농가 수익/추천이 아닙니다.

실행 단위는 [세션별 계획](sessions/README.md)에 정리했습니다. 공개 출처 검증은 세션 01, 현장·노동·판로·견적·위험 정보는 02~06에서 병행 수집하고, 외부 자료 대기 중에는 세션 07의 회계 코드 정비를 진행할 수 있습니다. 08~11의 후보 평가·시험/투자 검토는 후보별 근거 문턱을 충족한 범위에서만 진행합니다. **계획 문서 작성은 아래 근거 과제의 완료를 뜻하지 않습니다.**

1. **P1-01 공개 정보 검증 (진행 중):** 2022~2024 전국·지역 공식 자료집 게시물 존재를 확인하고 출처 레지스트리·장기형 전국 2024 단면·검증 테스트를 준비했습니다. **다른 연도 전국 일부 웹 수치 5행 확인, PDF/노동 검증·전북 작목별 정밀 수치 확보와 비교가능성 검토는 미완료**입니다. 코드북과 API 실데이터를 혼동하지 않습니다. **조사 밖 후보의 발견 전용 등록부·검사기를 준비했지만 실제 후보/새 소득자료는 0건이며, 공식 원문 검증은 계속 필요합니다.**
2. **P0-03/04 이용자·현장 정보 수집:** 실경작 면적, 토양, 배수, 용수, 인허가, 전기, 노동시간 12개월, 자금 여력. **자료 미제공이면 계속 UNKNOWN**.
3. **P1-02/03 시장·시설:** 구매처·등급·수수료·정산시점, 신축·임대·관수 비용에 대해 실제 문서/견적 범위를 확보합니다.
4. **P2 범용 작목×시설×면적 모델 (51개 후보·20개 작업 일정 원문 연결 + 다년 장부 설계):** 가정형 작업단계·시설비·판매 입금·월별 자금 비교를 구현합니다. 이후 실제 농가 작업일정과 비용·수량·품질·판로·견적을 확보한 범위부터 검증된 비교로 승격합니다. 기존 5개 가상 전략을 51개 품목에 복사하지 않습니다.

**완료 조건:** 출처/연도/지역/단위/작기 차이가 비교표에 드러나고, 실경작 가능성이 미확인인 작물이 자동으로 '부적합' 판정을 받지 않으며, 검증된 자료 없이 특정 작물을 권하지 않습니다.
