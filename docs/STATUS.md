## 다음 단계(우선순위)

1. **P1-01 공개 정보 검증 (진행 중):** 2022~2024 전국·지역 공식 자료집 게시물 존재를 확인하고 출처 레지스트리·장기형 전국 2024 단면·검증 테스트를 준비했습니다. **다른 연도 전국 일부 웹 수치 5행 확인, PDF/노동 검증·전북 작목별 정밀 수치 확보와 비교가능성 검토는 미완료**입니다. 코드북과 API 실데이터를 혼동하지 않습니다.
2. **P0-03/04 이용자·현장 정보 수집:** 실경작 면적, 토양, 배수, 용수, 인허가, 전기, 노동시간 12개월, 자금 여력. **자료 미제공이면 계속 UNKNOWN**.
3. **P1-02/03 시장·시설:** 구매처·등급·수수료·정산시점, 신축·임대·관수 비용에 대해 실제 문서/견적 범위를 확보합니다.
4. **P2 범용 작목×시설×면적 모델:** 충분히 비교 가능한 근거 후 구축. 기존 5개 가상 전략을 51개 품목에 복사하지 않습니다.

**완료 조건:** 출처/연도/지역/단위/작기 차이가 비교표에 드러나고, 실경작 가능성이 미확인인 작물이 자동으로 '부적합' 판정을 받지 않으며, 검증된 자료 없이 특정 작물을 권하지 않습니다.
