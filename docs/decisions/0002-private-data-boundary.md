# ADR-0002: 필지·거래 원본과 비식별 모형 입력을 분리한다

- **상태:** Accepted
- **날짜:** 2026-10-15
- **결정 범위:** 프라이버시/증빙 관리 설계. **증빙의 진위 인증은 아님**.
- **검토 책임:** 저장소 유지관리자, 실제 자료 검토자

## 상황

민감 자료에는 정확한 농지 위치·토지 식별정보, 실제 판매 정산서/견적/대출조건과 API 비밀정보가 포함될 수 있다. Git 저장소가 private여도 커밋 이력과 CI artifact 유출 위험이 있다. 재무모델은 2024 전국 조사값을 농장의 실거래로 취급해서는 안 된다.

## 대안

1. 모든 원본 PDF/영수증/주소를 Git에 보관 — *거부*: 필요 없는 민감정보 축적.
2. 공개 통계와 개인 실거래 자료를 단일 CSV로 병합 — *거부*: 출처와 보안 경계 무너짐.
3. 공개/파생 참고 데이터만 Git에 두고, 원본 거래/지번/일반 사적 기록은 무시되는 로컬 영역에 보관 — *채택*.

## 결정

원본 현장·계약·정산 자료는 **Git ignored \`data/private/\`, \`data/raw/\`, \`output/\` 등 적절한 비공개 위치**에 보관한다. Git에는 제삼자 보고통계/비식별 메타데이터/합성 검증용 결과만 남긴다. \`farm-strategy site-check\`는 **확인 상태 개수만** 출력한다. 금액을 반영하는 보정은 별도의 검토 확인과 파일 해시를 요구하며 기본 \`configs/base.json\`을 교체하지 않는다.

## 결과/검증

- 장점: 개인 위치/계좌/농장 운영 내역 노출과 무검증 기준값 교체 위험 감소.
- 제한: 데이터 해시는 파일 바이트 변경을 잡을 뿐, 영수증 진위나 사람의 검토 주장까지 인증하지 못한다.
- 재검토 조건: 안전한 외부 자료보관소·접근권한·보존정책에 대한 별도 요구가 확정될 때.
