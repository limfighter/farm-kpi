# 의사결정 기록(ADR)

ADR은 **코드·문서 운영과 데이터 해석 방식에 관한 확정된 설계 결정**입니다. 작물 선택, 토지 적합, 시설 허가, 대출 실행 승인을 대신하지 않습니다.

| 번호 | 제목 | 상태 | 날짜 |
| --- | --- | --- | --- |
| [0001](0001-evidence-first-open-crop-choice.md) | 데이터 확보 전에 작물과 시설을 미리 확정하지 않기 | Accepted | 2026-10-15 |
| [0002](0002-private-data-boundary.md) | 실제 농지·거래자료는 로컬 비공개로 격리 | Accepted | 2026-10-15 |

새 기록은 [템플릿](TEMPLATE.md)을 복사해 번호를 올리고, 검토한 대안·근거·결과를 남긴 뒤 PR을 엽니다. 과거 ADR을 소급해서 뒤집지 않고 **새 ADR로 대체(Superseded)**합니다.

현재 운영 상태는 [STATUS.md](../STATUS.md), 작성 규칙은 [CONTRIBUTING_DOCS.md](../CONTRIBUTING_DOCS.md)를 참고하세요.
