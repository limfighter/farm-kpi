# 1–2주 차 실행: 원본 통계 대조 및 농지 현장정보 입력

**상태 (2026-10-15):** 작물·품목별 면적·노지/신축/임대 선택은 모두 **미정**.
기존 5개 감자·쪽파·시설오이 시뮬레이션은 초안 예시일 뿐입니다.

## 1. 2024 농촌진흥청 51개 작목 원본 대조 (P0-02)

업로드된 **2024 농산물소득자료집 PDF (287쪽)**의 총괄표
PDF **17–19쪽**과 51개 작목별 노동시간 표 PDF **127–177쪽**을
기존 `data/reported/rda_2024_all_51_crop_candidates.csv`와 대조했습니다.

- 51/51: 각 작목의 **총수입·경영비·소득** 3개 값이 PDF의 해당 총괄표
  페이지에서 같은 순서로 연속 발견됨.
- 51/51: **자가노동·고용노동·합계 노동시간**이 해당 노동시간 PDF 페이지
  합계 부분에 존재함.
- 별도 자동검증: 51개의 소득률 반올림 일치(허용오차 0.051%p),
  수입−경영비−소득 차이 2원 이하(원자료 반올림 고려),
  자가+고용 노동 합계 오차 0.11시간 이내, 음수 작업시간 금지.
- **인삼(4년근)은 4년 1기작**, 나머지 자료는 해당 조사표 기준
  1기작 수치. 4년분을 임의로 연 소득으로 변환하지 않음.
- 원본 PDF는 **SHA256**으로 식별해
  `data/metadata/rda_2024_source_verification.json`에 크롭별 대조 개수를
  기록했으며, 원본 PDF 자체는 Git에 올리지 않음.
- 추출방법의 한계: 표의 총액/합계 셀 존재 여부를 검증한 것이며
  통계 생산기관 서명, 조사 농가 실제 지출, 전체 표의 세부 원가항목,
  전북 재배 적합성이나 2026 가격을 증명하지는 않음.

반복 검증 (원본 PDF를 별도 확보한 환경에서만 가능):

```bash
python -m pip install pymupdf
python scripts/verify_rda_pdf_source.py \
  --pdf "data/raw/2024_농산물소득자료집.pdf"
# 기존 정리된 51개 작목 행의 변조/증감을 CI에서 감지
python scripts/verify_rda_pdf_source.py --check
```

2024년 `R` 전국 조사의 총수입·소득은 **KRW/10a/작기**, 
현금흐름 모델은 **2026년 불변 KRW 1만 원 단위/연도**입니다.
국가 통계 경영비에 포함된 고용노동/시설 감가상각비가
현금 투자와 중복되지 않도록 해야 하며, 아직 어떤 통계 숫자도
`configs/base.json`에 이식하지 않았습니다.

## 2. 농지 및 운영 가능 조건 입력 양식 (P0-03/P0-04)

**권장 입력 방법:** [오프라인 브라운·세이지 현장 조사표](../dashboard/site-intake/index.html)를 브라우저로 열고, 12개 항목을 입력한 뒤 'JSON 저장'으로 내려받아 `data/private/`에 보관합니다. 이전에 저장한 JSON은 화면 안에서만 다시 불러올 수 있습니다. 서버 전송이나 자동 동기화는 없습니다. 파일 구조가 맞는지는 아래 `site-check` 명령으로 별도 검증하세요.

1. `data/templates/private_site_intake_TEMPLATE.json`을
   **로컬** `data/private/site-facts.json`으로 복사합니다.
2. 최초 값 `approx_gross_area_pyeong: 3000`은 개략적 총면적이며,
   **실제 재배 가능한 면적은 null(미확인)**입니다.
3. 12개 검증 항목에는 미확인인 경우 `UNKNOWN`, 추가 조사가 필요하면
   `FOLLOWUP_NEEDED`, 관련 문서를 확보했지만 신뢰성을 대조하지 않았으면
   `DOCUMENT_COLLECTED_UNVERIFIED`, 본인이 제약을 알고 있으면
   `USER_REPORTED_CONSTRAINT`을 입력합니다.
4. 문서 수집 시 출처 구분 `O/R/Q/T`, 원본을 식별할 수 있는
   **비개인·비좌표 참조 ID**, 확인 날짜만 기입합니다. 
   수집은 **검증·허가·적합 판정이 아닙니다**. 따라서 이 형식에서는
   `VERIFIED_FEASIBLE` 상태를 허용하지 않습니다.
5. 실제 경작가능 평수, 월별 자가노동 가능 시간 12개, 자체 조달 가능
   자금, 감당 가능한 월말 현금완충액, 첫 매출까지 허용 기간은
   모르거나 정하지 않았다면 `null`로 둡니다.
   **0은 실제 0이라는 관찰·결정을 뜻하므로 미확인 대신 사용 금지**.
6. 정확한 필지번호, 상세 주소/좌표, 개인 이름·연락처, 매매/대출
   식별번호, 거래명세서나 원본 증빙은 이 JSON에 **입력하지 않습니다**.
7. 작물과 시설 선택은 반드시 `UNDECIDED`로 남겨둡니다.
   적합성 및 투자비 검토 결과에 따라 별도의
   검토/결정 절차에서만 변경해야 합니다.

```bash
mkdir -p data/private output
cp data/templates/private_site_intake_TEMPLATE.json data/private/site-facts.json
# 위 사본을 수정하여 현장 확인사항 기입 (null/UNKNOWN 허용)
farm-strategy site-check \
  --file data/private/site-facts.json \
  --output output/site-status-redacted.json
```

내보내는 `output/site-status-redacted.json`에는 **각 게이트의 확인 상태 개수,
미확인 항목명, 노동 시간 입력 월수, 영역 입력 여부**만 있습니다.
실제 개인 메모·참조 ID·금액·좌표·필지번호는 출력하지 않습니다.
`data/private/`와 `output/`은 Git에서 무시됩니다.

필수 조사 순서 (작물 선정을 요구하지 않음):

| 우선 | 확인할 항목 | 구할 곳/방법 | 다음 판단에 미치는 영향 |
| --- | --- | --- | --- |
| 1 | 실제 경작가능 면적·현황·도로 접근 | 현장 확인, 토지 이용 정보 | 작부계획 상한 |
| 2 | 토양검정·배수·침수 이력 | 시군 농업기술센터, 흙토람, 현장 조사 | 농작업 가능성/작물 적성 |
| 3 | 관개수 공급과 수량·권리 | 현장/관계기관 | 노지·시설 모두의 필수 제약 |
| 4 | 농지 전용·시설 설치 제한 | 토지이음 및 관할 행정기관 | 시설 선택 실현 가능성 |
| 5 | 전기 용량·난방·저장·물류 | 공급사업자/현장·업체 견적 | 시설·저장 투자비 |
| 6 | 12개월 작업 가능시간/인력·유동성 한계 | 경영자 계획(미정 허용) | 면적/시설 확대 한계 |
| 7 | 작물·등급별 구매처/순정산기간 | 유통업체·농협·시장법인 | 실제 판매 및 현금수취 가능성 |

**현재 실제 농지별 12개 항목은 전부 미확인**이며, 
양식/프로그램 개발 자체가 조사를 완료했다는 의미는 아닙니다.

## 3. 다음 착수 (P1, 외부 데이터 필요)

- 2020–2023 및 2025 작목 통계, 지역 단위 제공 여부를
  조사해 2024 전국 표와 명확히 분리한다.
- 작물별 생산량/실수취 가격/경영비에서 현금비용과 감가상각을
  구분하는 재무조정 표를 설계한다.
- 본인 농지에 대한 기초 현장 요건이 수집되기 전에는
  51개 작목 투자 점수·ROI 순위를 산출하거나
  자동으로 특정 작물을 제거하지 않는다.
- 서면 신축·임대 견적은 `Q`(견적), 실제 정산은 `T`(거래)로
  기록하며, 자료 없을 때는 결측으로 보존한다.
