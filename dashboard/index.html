빠른 실행 가이드

현재 구조를 다시 만들거나 결과를 갱신할 때 자주 쓰는 명령입니다.

전략 비교 다시 생성

farm-strategy compare --seed 42 --paths 1000 --stress-matrix \ --output output/compare-model-only.json \ --csv output/compare-model-only.csv

단일 전략 월별 상세 보기

farm-strategy forecast --plan new_cucumber_house \ --seed 42 --paths 1000 --monthly-details \ --output output/monthly-example.json

실제 증빙 형식 검사

farm-strategy evidence-check \ --file data/private/my_evidence.csv
주의: 이 화면의 결과는 실측 매출, 실제 공사 견적, 승인된 대출조건으로 교정되기 전의 가정 기반 모델입니다.
